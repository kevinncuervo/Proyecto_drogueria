
# Sistema de Gestión de Inventario y Venta de una Droguería

## Descripción
Proyecto académico de Bases de Datos I desarrollado en PostgreSQL 18.

El sistema permitirá administrar proveedores, entregas de mercancía, productos, lotes, clientes, ventas y facturación.

## Taller III — Implementación Física y SQL

El proyecto contempla seis partes:

1. Diseño físico y DDL.
2. Restricciones e integridad.
3. Datos sintéticos con IA.
4. Manipulación de datos y consultas SQL.
5. Vistas y transacciones.
6. NL2SQL con controles de seguridad.

## Modelo de datos

El sistema estará compuesto por nueve tablas:

- proveedor
- entrega
- producto
- lote
- cliente
- venta
- detalle_venta
- detalle_lote_venta
- factura
